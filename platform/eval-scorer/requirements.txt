# eval-scorer (M4 Task 4): policy-adherence scores, computed from the trace.
#
# House style: nothing floats. Direct dependencies first, each with the reason
# it is here; the transitive closure below, pinned exactly as `uv pip install`
# resolved it into this service's own clean `.venv` on 2026-09-13.
#
# There is no HTTP framework here, and that is a decision rather than an
# omission. `scorer/server.py` routes two paths with the standard library's
# `http.server`; every framework already in this repo's closure would arrive
# with an instrumentation library whose spans would land in the *caller's*
# trace -- the one place these scores must not be. See
# `scorer/emit.py::configure`.

# The scoring SDK the M1 spike validated (M1 spec §13). 0.2.8 is the newest
# release on PyPI, verified against the package's own JSON API on 2026-09-13
# (0.2.5 2026-03-05, 0.2.6 2026-03-12, 0.2.7 2026-03-17, 0.2.8 2026-03-30; no
# newer release and no pre-release). It emits scores as `gen_ai.evaluation.*`
# OTel spans through whatever TracerProvider is globally installed -- which is
# what lets them ride the existing OTLP pipeline with no exporter of their
# own, the property the spike recorded and this milestone depends on.
#
# It is also the only reason `botocore`, `jmespath`, `python-dateutil` and
# `six` appear below: `botocore>=1.29.0` is one of its five hard dependencies
# (its `AWSSigV4OTLPExporter`, which this service does not use and cannot use
# -- there is no AWS here). Unavoidable without vendoring the one function
# this service calls, which would be a fork of a spike-validated dependency to
# save 15 MB of image.
opensearch-genai-observability-sdk-py==0.2.8

# OpenTelemetry. Versions match every other Python service's pin
# (opentelemetry-sdk/-api/-exporter-otlp-proto-http 1.44.0) -- cross-cutting
# packages already verified elsewhere in this repo, and re-resolving them
# independently per new service would risk landing on a different SDK version
# with no reason tied to this service's own needs. The SDK above declares
# `opentelemetry-*<2,>=1.20.0`, so 1.44.0 satisfies it rather than forcing it.
opentelemetry-sdk==1.44.0
opentelemetry-api==1.44.0
opentelemetry-exporter-otlp-proto-http==1.44.0

# --- test-only, gated by the same advisory-pin discipline as every other
