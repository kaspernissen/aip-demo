#     main.py builds and StarletteInstrumentor attaches to) does not exist.
#   * 1.2.3 still does not extract inbound trace context and its spans carry
#     no attributes, so the StarletteInstrumentor workaround in main.py is
#     still required (docs/upstream-findings.md Finding 1,
#     docs/telemetry-contract.md Gap 1).
