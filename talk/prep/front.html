The talk in one paragraph

Agents change the nature of complexity: the model draws the call graph at run time, and an agent will do whatever its tools let it do. So the boundary can’t live in the prompt. The platform has to decide what an agent may do, through identity, reach, per-call capability, a live autonomy level and a keystone the agent can’t edit. It has to trace what the agent actually did, as one OpenTelemetry trace per claim with every decision as a span. And it has to prove it afterwards from that trace, with evaluations that read the agent’s own spans. Every piece is an upstream CNCF or AAIF project. The only code Northstar owns is its rules.

The three things the room should remember

  1. Guardrails live in the platform, not in the prompt, and the agent can’t move them.
  2. Instrument decisions, not only errors. A permit, a hold and a sign-off are spans with a rule, a limit and an identity.
  3. Build it from upstream projects. Own only the rules.
