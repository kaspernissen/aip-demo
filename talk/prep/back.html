Glossary

Each term in plain words, then what it is in Northstar.

TermPlain wordsIn Northstar
A2A (Agent2Agent)The protocol one agent uses to hand a task to another agent. A task has a lifecycle (working, input required, completed).Claims agent → settlement agent. a2a-sdk; trace context read by our own middleware.
AAIFAgentic AI Foundation, a Linux Foundation home for agent protocols and tools.MCP, A2A and agentgateway sit there.
Admission controlA Kubernetes API checkpoint that can reject a change before it is stored.Kyverno’s keystone policy.
agentgatewayA proxy built for agent traffic (MCP, A2A, model calls). It checks identity and policy on every call.The only door to payments-mcp (port 3000) and to the model (port 4000).
AgentEvalsAn open-source evaluator that grades agent runs from their OpenTelemetry traces.Five evaluators per claim. Grades written back as gen_ai.evaluation.result.
Autonomy levelHow much the agent may do on its own today.assisted (€0) or autonomous (€6,000), from one OpenFeature flag.
BaggageKey/value pairs that travel with the trace context across hops.The claim id from the browser onwards.
CELCommon Expression Language: small, side-effect-free expressions, fast to evaluate.The gateway’s caller allowlist and €50,000 ceiling. Kyverno’s match condition.
Collector (OTel)A pipeline that receives, processes and exports telemetry.One Collector, no sampling. Exports to Jaeger, Prometheus, Weaver live-check, AgentEvals, and optionally Dash0.
Content captureRecording the actual prompts and answers in spans. Opt-in, because it is sensitive.On, so the trace says why as well as what.
Fail closedIf the checker can’t answer, the answer is no.The gateway’s remote guardrail. flagd failures fall back to assisted.
flagdA feature-flag daemon that serves flags to OpenFeature SDKs.A sidecar beside the policy decision service.
gen_ai.*OpenTelemetry semantic conventions for model and agent calls.invoke_agent, chat, execute_tool spans.
KeystoneThe rule that the agent can never edit what defines its own authority.Kyverno ValidatingPolicy agents-cannot-edit-their-own-authority.
LinkerdA service mesh: a proxy beside every pod adds mTLS, identity-based authorization and telemetry.Only the gateway’s mTLS identity may reach payments-mcp and the PDS.
LLM-as-judgeUsing a second model to grade something that needs meaning, not rules.prompt_injection evaluator. It only flags, because judges drift.
MCPModel Context Protocol: how an agent lists and calls tools.Settlement agent → gateway → payments-mcp.
mTLSTLS where both sides show a certificate, so each knows who the other is.Linkerd, between every meshed pod.
NetworkPolicyKubernetes firewall rules, enforced by the network plugin in the node.Agents may reach the gateway (3000, 4000) and nothing on the internet.
OpenFeatureA CNCF standard API for asking “what is this flag’s value for this caller?”. The provider behind it is pluggable.The PDS asks for autonomy-level by SPIFFE ID.
PDSPolicy Decision Service: Northstar’s own code that permits or denies, and records why.platform/policy-decision-service, gRPC on 9100.
Safe Operating ModelRings of least privilege: identity, reach, capability (and data), with a keystone.From Francesco Beltramini (ControlPlane). The data ring is out of scope.
Semantic conventionsThe agreed names for telemetry attributes, so every tool reads them the same way.http.*, gen_ai.*, plus our own northstar.* in Weaver.
Span / trace / linkA span is one step. A trace is all steps of one run. A link joins two traces without nesting them.One trace per claim. The human approval is a second trace, linked back.
SPIFFE / SPIRE / SVIDSPIFFE is the identity standard. SPIRE issues the identities. An SVID is the signed, short-lived document that carries one.spiffe://northstar.local/ns/<ns>/sa/<sa>, shown to the gateway as a JWT.
traceparentThe W3C header that carries the trace id from hop to hop.HTTP and A2A headers, MCP params._meta.
WeaverOpenTelemetry’s tool to define, check, document and live-check telemetry names.telemetry/registry/, scripts/check-registry.sh, live-check in-cluster.
