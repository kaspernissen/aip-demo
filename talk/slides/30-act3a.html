Core · Identity

SPIFFE and SPIRE, in one minute

SPIFFE

the standard · what a passport looks like

An ID for a workload, not a person: spiffe://northstar.local/ns/…/sa/…, carried in a short-lived signed document, the SVID.

SPIRE

the issuer · the passport office

An agent on every node checks where a pod runs before the server signs: its namespace, its service account.

  1. A pod asksover a local socket, no secret
  2. SPIRE checksnamespace, service account
  3. SPIRE signsan SVID that expires soon
  4. The pod shows itat the gateway, on every call

No password to leak. The identity is proven by where it runs, not by what it says.

Ring 2 · Capability

What CEL decides, and when the gateway asks

  1. Who is calling?jwtAuth · the SPIFFE ID
  2. What the request provesCEL on the route · tool, arguments
  3. What needs a lookupmcpGuardrails · asks the decision service
  4. The toolonly on a yes

CEL, inside the gateway

  • who is calling, which tool, how much
  • a limit per identity, a hard ceiling for everyone
  • no code to run, config reloads in seconds
mcp.tool.name != "execute_payment"
  || mcp.tool.arguments.amount <= 50000

Can’t look anything up. Its no is 403 authorization failed.

Delegated, to a decision service

  • the live autonomy level, from OpenFeature
  • the ledger: the agent pays only what it proposed, a human only what waits
  • a refusal the agent can explain, rule and limit
  • its own span: northstar.policy.decision

If it can’t answer, the answer is no: failClosed.

CEL for what the request can prove. Delegate when the answer has to look something up.
