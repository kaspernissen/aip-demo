# M1.1 Walking Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove that a single OpenTelemetry trace survives a browser → A2A → A2A → MCP → HTTP call chain across TypeScript, Python and Go, with zero LLM involvement.

**Architecture:** The narrowest path through the Northstar architecture that still crosses every protocol and language boundary. All agent logic is hardcoded. A kind cluster runs an OTel Collector and Jaeger; a trace-assertion harness queries Jaeger's API and asserts on trace *shape*, so telemetry is test-driven from the first task rather than inspected by eye at the end.

**Tech Stack:** kind, Kubernetes, OpenTelemetry Collector, Jaeger, Go (`otelhttp`), Python (`a2a-sdk[telemetry]`, `fastmcp`, `mcp`), TypeScript/Next.js (`@a2a-js/sdk`, OpenTelemetry JS web), pytest.

**Spec:** `docs/superpowers/specs/2026-09-07-northstar-m1-connected-design.md`

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec.

- **Telemetry rule:** Use the telemetry the frameworks actually emit. Verify per component. Instrument only our own code. Where a convention gap exists, report the gap — never invent a bespoke convention for a tool we did not write.
- **MCP transport is streamable HTTP.** Never stdio — stdio cannot traverse agentgateway in M2.
- **MCP trace context propagates via the JSON-RPC `params._meta` bag** (SEP-414), with `traceparent`, `tracestate` and `baggage` keys left **unprefixed**. It does *not* propagate via HTTP headers.
- **The MCP tool-name attribute is `gen_ai.tool.name`.** `mcp.tool.name` does not exist in the semantic conventions.
- **`FASTMCP_TELEMETRY_MODE=native`** (the default). A TracerProvider **must be set before importing FastMCP**, or its instrumentation binds to a no-op.
- **`DISABLE_OTEL_INSTRUMENTATION` must never be set to `true`** — in the `a2a-sdk` it takes precedence over all other OTel configuration.
- **`execute_payment` declares `destructiveHint: true`** in its own tool schema. Consequence is declared in the protocol, not pattern-matched from tool names.
- **No agent touches another agent's MCP server.** `settlement-agent` owns payments.
- **Fixtures are deterministic.** No randomness anywhere in domain logic.
- **`northstar.claim.id`** is set once into OTel baggage by `claims-agent` at intake and propagates from there. Our own spans set it directly; our own service processes enable a baggage span processor. Nothing is injected into third-party infrastructure telemetry.
- **Namespaces:** `northstar-agents`, `northstar-tools`, `northstar-systems`, `observability`.
- **Vendor neutrality:** Jaeger exporter always on. A second OTLP exporter is added only when `DASH0_AUTH_TOKEN` is set, with no application code change.
- **Target platform:** kind on a 16 GB Mac. Stage 1 budget is ~3 GB of cluster memory.
- **Cluster name:** `northstar`.
- **No LLM in M1.1.** All agent decision logic is hardcoded. PydanticAI arrives in M1.2.

```python
def synthetic_trace():
    """Emit a two-span trace through the real collector, then read it back."""
    marker = uuid.uuid4().hex
    service_name = f"harness-probe-{marker}"

    provider = TracerProvider(resource=Resource.create({"service.name": service_name}))
    provider.add_span_processor(
        BatchSpanProcessor(OTLPSpanExporter(endpoint=f"{OTLP_ENDPOINT}/v1/traces"))
    )

            pass

    provider.shutdown()

    return client.wait_for_trace(service=service_name, operation="probe.parent", timeout=90)
```

```python
"""Jaeger query client and trace-shape assertions.

Trace shape is the contract this project rests on: if context propagation
breaks anywhere in the chain, every other test still passes while the demo
becomes worthless. These assertions are the guard against that.
"""
from __future__ import annotations

import time
from dataclasses import dataclass
from typing import Any

import requests


@dataclass(frozen=True)
class Span:
    operation: str
    service: str
    span_id: str
    parent_id: str | None
    kind: str | None
    attrs: dict[str, Any]


class Trace:
    def __init__(self, raw: dict[str, Any]):
        self._raw = raw
        process_names = {
            pid: proc.get("serviceName", "unknown")
            for pid, proc in raw.get("processes", {}).items()
        }
        self.spans: list[Span] = []
        for raw_span in raw.get("spans", []):
            attrs = {tag["key"]: tag["value"] for tag in raw_span.get("tags", [])}
            parent_id = None
            for ref in raw_span.get("references", []):
                if ref.get("refType") == "CHILD_OF":
                    parent_id = ref.get("spanID")
            self.spans.append(
                Span(
                    operation=raw_span["operationName"],
                    service=process_names.get(raw_span.get("processID"), "unknown"),
                    span_id=raw_span["spanID"],
                    parent_id=parent_id,
                    kind=attrs.get("span.kind"),
                    attrs=attrs,
                )
            )

    @property
    def trace_id(self) -> str:
        return self._raw["traceID"]

    def span(self, operation: str) -> Span:
        matches = [s for s in self.spans if s.operation == operation]
        if not matches:
            raise AssertionError(
                f"no span named {operation!r}; present: {sorted(s.operation for s in self.spans)}"
            )
        if len(matches) > 1:
            raise AssertionError(f"{len(matches)} spans named {operation!r}, expected one")
        return matches[0]

    def spans_named(self, operation: str) -> list[Span]:
        return [s for s in self.spans if s.operation == operation]

    def has_span(self, operation: str) -> bool:
        return any(s.operation == operation for s in self.spans)

    def services(self) -> set[str]:
        return {s.service for s in self.spans}

    def roots(self) -> list[Span]:
        return [s for s in self.spans if s.parent_id is None]

    def orphans(self) -> list[Span]:
        """Spans whose declared parent is not present in this trace."""
        ids = {s.span_id for s in self.spans}
        return [s for s in self.spans if s.parent_id is not None and s.parent_id not in ids]


class JaegerClient:
    def __init__(self, base_url: str = "http://localhost:16686"):
        self.base_url = base_url.rstrip("/")

    def services(self) -> list[str]:
        resp = requests.get(f"{self.base_url}/api/services", timeout=10)
        resp.raise_for_status()
        return resp.json().get("data") or []

    def find_trace(
        self,
        service: str,
        operation: str | None = None,
        tags: dict[str, str] | None = None,
        lookback: str = "1h",
        limit: int = 20,
    ) -> Trace | None:
        params: dict[str, Any] = {"service": service, "lookback": lookback, "limit": limit}
        if operation:
            params["operation"] = operation
        if tags:
            import json

            params["tags"] = json.dumps(tags)
        resp = requests.get(f"{self.base_url}/api/traces", params=params, timeout=15)
        resp.raise_for_status()
        data = resp.json().get("data") or []
        if not data:
            return None
        return Trace(data[0])

    def get_trace(self, trace_id: str) -> Trace:
        resp = requests.get(f"{self.base_url}/api/traces/{trace_id}", timeout=15)
        resp.raise_for_status()
        data = resp.json().get("data") or []
        if not data:
            raise AssertionError(f"trace {trace_id} not found")
        return Trace(data[0])

    def wait_for_trace(
        self,
        service: str,
        operation: str | None = None,
        tags: dict[str, str] | None = None,
        timeout: float = 60.0,
        interval: float = 2.0,
    ) -> Trace:
        deadline = time.time() + timeout
        last_error: Exception | None = None
        while time.time() < deadline:
            try:
                trace = self.find_trace(service, operation=operation, tags=tags)
                if trace is not None:
                    return trace
            except requests.RequestException as exc:
                last_error = exc
            time.sleep(interval)
        detail = f" (last error: {last_error})" if last_error else ""
        raise AssertionError(
            f"no trace for service={service!r} operation={operation!r} "
            f"tags={tags!r} within {timeout}s{detail}"
        )


def assert_single_root(trace: Trace) -> None:
    roots = trace.roots()
    if len(roots) != 1:
        described = [f"{s.service}:{s.operation}" for s in roots]
        raise AssertionError(f"expected exactly one root span, found {len(roots)}: {described}")


def assert_no_orphans(trace: Trace) -> None:
    orphans = trace.orphans()
    if orphans:
        described = [f"{s.service}:{s.operation} (parent {s.parent_id})" for s in orphans]
        raise AssertionError(f"orphan spans present, context propagation is broken: {described}")


def assert_parent_child(trace: Trace, parent_op: str, child_op: str) -> None:
    parent = trace.span(parent_op)
    children = [s for s in trace.spans if s.parent_id == parent.span_id]
    if not any(s.operation == child_op for s in children):
        described = sorted(s.operation for s in children)
        raise AssertionError(
            f"{child_op!r} is not a child of {parent_op!r}; actual children: {described}"
        )


def assert_span_kind(trace: Trace, operation: str, kind: str) -> None:
    span = trace.span(operation)
    if span.kind != kind:
        raise AssertionError(f"{operation!r} has span.kind={span.kind!r}, expected {kind!r}")


def assert_attr_on_all_spans(
    trace: Trace, key: str, services: set[str] | None = None
) -> None:
    """Assert an attribute is present on every span, optionally limited to some services."""
    missing = [
        f"{s.service}:{s.operation}"
        for s in trace.spans
        if (services is None or s.service in services) and key not in s.attrs
    ]
    if missing:
        raise AssertionError(f"attribute {key!r} missing from spans: {sorted(missing)}")
```

```go
package main

import (
	"errors"
	"fmt"
	"sync"
)

// Payment status values. Kept as strings so the JSON contract in
// contracts/openapi/payments-api.yaml is obvious from the code.
const (
	StatusProposed = "proposed"
	StatusExecuted = "executed"
)

var (
	ErrNotFound = errors.New("payment not found")
	ErrExecuted = errors.New("payment already executed")
)

type Payment struct {
	PaymentID string  `json:"paymentId"`
	ClaimID   string  `json:"claimId"`
	Amount    float64 `json:"amount"`
	Currency  string  `json:"currency"`
	Status    string  `json:"status"`
}

// store holds payments in memory. Deterministic sequential IDs matter: the
// demo's numbers must be identical on every run.
type store struct {
	mu       sync.Mutex
	payments map[string]Payment
	nextID   int
}

func newStore() *store {
	return &store{payments: make(map[string]Payment), nextID: 1}
}

func (s *store) propose(claimID string, amount float64, currency string) Payment {
	s.mu.Lock()
	defer s.mu.Unlock()

	payment := Payment{
		PaymentID: fmt.Sprintf("PAY-%06d", s.nextID),
		ClaimID:   claimID,
		Amount:    amount,
		Currency:  currency,
		Status:    StatusProposed,
	}
	s.nextID++
	s.payments[payment.PaymentID] = payment
	return payment
}

func (s *store) execute(paymentID string) (Payment, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	payment, ok := s.payments[paymentID]
	if !ok {
		return Payment{}, ErrNotFound
	}
	if payment.Status == StatusExecuted {
		return Payment{}, ErrExecuted
	}
	payment.Status = StatusExecuted
	s.payments[paymentID] = payment
	return payment, nil
}

func (s *store) get(paymentID string) (Payment, error) {
	s.mu.Lock()
	defer s.mu.Unlock()

	payment, ok := s.payments[paymentID]
	if !ok {
		return Payment{}, ErrNotFound
	}
	return payment, nil
}
```

```go
package main

import (
	"encoding/json"
	"errors"
	"net/http"

	"go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp"
)

type proposeRequest struct {
	ClaimID  string  `json:"claimId"`
	Amount   float64 `json:"amount"`
	Currency string  `json:"currency"`
}

func writeJSON(w http.ResponseWriter, status int, body any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(body)
}

func writeError(w http.ResponseWriter, status int, message string) {
	writeJSON(w, status, map[string]string{"error": message})
}

// newRouter wires the HTTP surface. Each route is wrapped individually with
// otelhttp so the span name is the route template rather than the raw path,
// keeping span names low-cardinality per HTTP semantic conventions.
func newRouter(s *store) http.Handler {
	mux := http.NewServeMux()

	handle := func(pattern, spanName string, h http.HandlerFunc) {
		mux.Handle(pattern, otelhttp.NewHandler(h, spanName))
	}

	handle("GET /healthz", "GET /healthz", func(w http.ResponseWriter, r *http.Request) {
		writeJSON(w, http.StatusOK, map[string]string{"status": "ok"})
	})

	handle("POST /payments/propose", "POST /payments/propose", func(w http.ResponseWriter, r *http.Request) {
		var req proposeRequest
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
			writeError(w, http.StatusBadRequest, "malformed JSON body")
			return
		}
		if req.ClaimID == "" {
			writeError(w, http.StatusBadRequest, "claimId is required")
			return
		}
		if req.Amount < 0 {
			writeError(w, http.StatusBadRequest, "amount must not be negative")
			return
		}
		if req.Currency == "" {
			req.Currency = "EUR"
		}
		writeJSON(w, http.StatusCreated, s.propose(req.ClaimID, req.Amount, req.Currency))
	})

	handle("POST /payments/{paymentId}/execute", "POST /payments/{paymentId}/execute",
		func(w http.ResponseWriter, r *http.Request) {
			payment, err := s.execute(r.PathValue("paymentId"))
			switch {
			case errors.Is(err, ErrNotFound):
				writeError(w, http.StatusNotFound, "payment not found")
			case errors.Is(err, ErrExecuted):
				writeError(w, http.StatusConflict, "payment already executed")
			case err != nil:
				writeError(w, http.StatusInternalServerError, "unexpected error")
			default:
				writeJSON(w, http.StatusOK, payment)
			}
		})

	handle("GET /payments/{paymentId}", "GET /payments/{paymentId}",
		func(w http.ResponseWriter, r *http.Request) {
			payment, err := s.get(r.PathValue("paymentId"))
			if errors.Is(err, ErrNotFound) {
				writeError(w, http.StatusNotFound, "payment not found")
				return
			}
			writeJSON(w, http.StatusOK, payment)
		})

	return mux
}
```

```go
package main

import (
	"context"
	"fmt"
	"os"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp"
	"go.opentelemetry.io/otel/propagation"
	"go.opentelemetry.io/otel/sdk/resource"
	sdktrace "go.opentelemetry.io/otel/sdk/trace"
	semconv "go.opentelemetry.io/otel/semconv/v1.26.0"
)

// initTracing configures the global TracerProvider from standard OTEL_*
// environment variables. Nothing custom: OTEL_EXPORTER_OTLP_ENDPOINT and
// OTEL_SERVICE_NAME are honoured by the SDK and by the manifests.
func initTracing(ctx context.Context) (func(context.Context) error, error) {
	serviceName := os.Getenv("OTEL_SERVICE_NAME")
	if serviceName == "" {
		serviceName = "payments-api"
	}

	exporter, err := otlptracehttp.New(ctx)
	if err != nil {
		return nil, fmt.Errorf("creating OTLP exporter: %w", err)
	}

	res, err := resource.Merge(
		resource.Default(),
		resource.NewWithAttributes(
			semconv.SchemaURL,
			semconv.ServiceName(serviceName),
		),
	)
	if err != nil {
		return nil, fmt.Errorf("building resource: %w", err)
	}

	provider := sdktrace.NewTracerProvider(
		sdktrace.WithBatcher(exporter),
		sdktrace.WithResource(res),
	)
	otel.SetTracerProvider(provider)

	// W3C trace context and baggage. Baggage matters from Task 7 onward:
	// northstar.claim.id rides in it.
	otel.SetTextMapPropagator(propagation.NewCompositeTextMapPropagator(
		propagation.TraceContext{},
		propagation.Baggage{},
	))

	return provider.Shutdown, nil
}
```

```go
package main

import (
	"context"
	"errors"
	"log"
	"net/http"
	"os"
	"os/signal"
	"syscall"
	"time"
)

func main() {
	ctx := context.Background()

	shutdownTracing, err := initTracing(ctx)
	if err != nil {
		log.Fatalf("initialising tracing: %v", err)
	}
	defer func() {
		shutdownCtx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
		defer cancel()
		if err := shutdownTracing(shutdownCtx); err != nil {
			log.Printf("shutting down tracing: %v", err)
		}
	}()

	port := os.Getenv("PORT")
	if port == "" {
		port = "8080"
	}

	srv := &http.Server{
		Addr:              ":" + port,
		Handler:           newRouter(newStore()),
		ReadHeaderTimeout: 5 * time.Second,
	}

	go func() {
		log.Printf("payments-api listening on :%s", port)
		if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
			log.Fatalf("serving: %v", err)
		}
	}()

	stop := make(chan os.Signal, 1)
	signal.Notify(stop, os.Interrupt, syscall.SIGTERM)
	<-stop

	shutdownCtx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	if err := srv.Shutdown(shutdownCtx); err != nil {
		log.Printf("shutting down server: %v", err)
	}
}
```

```python
"""HTTP client for the payments system of record.

Instrumentation note: no spans are created here by hand. The httpx
instrumentation registered in bootstrap.py emits CLIENT spans following HTTP
semantic conventions, and injects trace context into outbound headers.
"""
from __future__ import annotations

import httpx


class PaymentsClient:
    def __init__(
        self,
        base_url: str,
        transport: httpx.BaseTransport | None = None,
        timeout: float = 10.0,
    ):
        self._client = httpx.Client(
            base_url=base_url.rstrip("/"), transport=transport, timeout=timeout
        )

    def propose(self, claim_id: str, amount: float, currency: str = "EUR") -> dict:
        response = self._client.post(
            "/payments/propose",
            json={"claimId": claim_id, "amount": amount, "currency": currency},
        )
        response.raise_for_status()
        return response.json()

    def execute(self, payment_id: str) -> dict:
        response = self._client.post(f"/payments/{payment_id}/execute")
        response.raise_for_status()
        return response.json()

    def get(self, payment_id: str) -> dict:
        response = self._client.get(f"/payments/{payment_id}")
        response.raise_for_status()
        return response.json()
```

```python
"""OpenTelemetry bootstrap.

MUST be imported before fastmcp. FastMCP's instrumentation binds to whatever
TracerProvider is installed at import time; if the SDK is not configured yet it
binds to a no-op and every MCP span is silently lost.

from opentelemetry import trace
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.instrumentation.httpx import HTTPXClientInstrumentor
from opentelemetry.sdk.resources import Resource
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor


def configure() -> None:
    service_name = os.environ.get("OTEL_SERVICE_NAME", "payments-mcp")
    provider = TracerProvider(resource=Resource.create({"service.name": service_name}))
    provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter()))
    trace.set_tracer_provider(provider)

    # Emits CLIENT spans for calls to payments-api and injects trace context
    # into outbound HTTP headers.
    HTTPXClientInstrumentor().instrument()
```

```python
This is the test that catches the params._meta propagation trap: if MCP context
were assumed to travel in HTTP headers, the payments-api span would land in a
separate trace and test_mcp_span_is_parent_of_payments_api_span would fail.

import uuid

from mcp.client.streamable_http import streamablehttp_client

async def _call_tools(claim_id: str) -> dict:

            payment = proposed.structuredContent or {}
            payment_id = payment.get("paymentId") or payment.get("result", {}).get("paymentId")
            executed = await session.call_tool("execute_payment", {"payment_id": payment_id})
            return {"payment_id": payment_id, "executed": executed}

def test_tool_call_span_carries_mcp_semantic_conventions(mcp_trace):
    span = mcp_trace.span("tools/call execute_payment")
    assert span.attrs.get("mcp.method.name") == "tools/call"
    # Tool name lives in the GenAI namespace. mcp.tool.name does not exist.

def test_mcp_span_is_parent_of_payments_api_span(mcp_trace):
    """Guards the params._meta propagation contract."""
    mcp_span = mcp_trace.span("tools/call execute_payment")
    descendants = {s.span_id: s for s in mcp_trace.spans}

    def is_descendant_of(span, ancestor_id):
        seen = set()
        current = span
        while current.parent_id and current.parent_id not in seen:
            if current.parent_id == ancestor_id:
                return True
            seen.add(current.parent_id)
            current = descendants.get(current.parent_id)
            if current is None:
                return False
        return False

    api_spans = [
        s for s in mcp_trace.spans
        if s.service == "payments-api" and "execute" in s.operation
```

```python
from __future__ import annotations


def decide_settlement(claim: dict) -> dict:
```

Create `agents/settlement-agent/mcp_tools.py`:

```python
"""MCP client for payments-mcp.

settlement-agent is the only agent permitted to reach payments-mcp. That
boundary is configuration here and enforcement at the gateway in M2.

Trace context crosses this boundary in the JSON-RPC params._meta bag, handled
by the MCP SDK. Nothing is injected into HTTP headers by hand.
"""
from __future__ import annotations

from typing import Any

from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client


def _unwrap(result: Any) -> dict:
    """Extract the structured payload from a CallToolResult."""
    structured = getattr(result, "structuredContent", None)
    if isinstance(structured, dict):
        # FastMCP wraps scalar and dict returns under "result" in some versions.
        return structured.get("result", structured)
    raise ValueError(f"tool call returned no structured content: {result!r}")


class PaymentsTools:
    def __init__(self, mcp_url: str):
        self._mcp_url = mcp_url

    async def _call(self, tool: str, arguments: dict) -> dict:
        async with streamablehttp_client(self._mcp_url) as (read, write, _):
            async with ClientSession(read, write) as session:
                await session.initialize()
                return _unwrap(await session.call_tool(tool, arguments))

    async def propose(self, claim_id: str, amount: float, currency: str = "EUR") -> dict:
        return await self._call(
            "propose_payment",
            {"claim_id": claim_id, "amount": amount, "currency": currency},
        )

    async def execute(self, payment_id: str) -> dict:
        return await self._call("execute_payment", {"payment_id": payment_id})
```

```python
"""A2A executor for settlement-agent.

M1.1 has no LLM. The executor parses the incoming message, calls
decide_settlement, then drives payments-mcp: propose, then execute.

In M1.1 it executes unconditionally. That is the point: €6,200 leaves the
company because a message asked for it. M2 puts a policy decision in the path.
"""
from __future__ import annotations

import json
import logging
import os

from a2a.server.agent_execution import AgentExecutor, RequestContext
from a2a.server.events import EventQueue
from a2a.utils import new_agent_text_message

from mcp_tools import PaymentsTools
from settlement import decide_settlement

logger = logging.getLogger(__name__)


class SettlementAgentExecutor(AgentExecutor):
    def __init__(self, payments: PaymentsTools | None = None):
        self._payments = payments or PaymentsTools(
            os.environ.get("PAYMENTS_MCP_URL", "http://payments-mcp:8000/mcp")
        )

    async def execute(
        self, request_context: RequestContext, event_queue: EventQueue
    ) -> None:
        # Named request_context, not context: `context` shadows
        # opentelemetry.context, which Task 7 needs in the claims-agent
        # executor. Keeping the name consistent across agents avoids a rename.
        claim = json.loads(request_context.get_user_input())

        decision = decide_settlement(claim)
        await event_queue.enqueue_event(
            new_agent_text_message(f"Assessed settlement: {decision['narrative']}")
        )

        proposed = await self._payments.propose(
            claim["claimId"], decision["amount"], decision["currency"]
        )
        payment_id = proposed["paymentId"]
        await event_queue.enqueue_event(
            new_agent_text_message(f"Proposed payment {payment_id}.")
        )

        executed = await self._payments.execute(payment_id)
        await event_queue.enqueue_event(
            new_agent_text_message(
                json.dumps(
                    {
                        "claimId": claim["claimId"],
                        "paymentId": payment_id,
                        "amount": executed["amount"],
                        "currency": executed["currency"],
                        "status": executed["status"],
                        "narrative": decision["narrative"],
                    }
                )
            )
        )

    async def cancel(
        self, request_context: RequestContext, event_queue: EventQueue
    ) -> None:
        raise NotImplementedError("settlement-agent does not support cancellation in M1")
```

```python
"""Claim intake parsing.

Deliberately strict and deterministic in M1.1. In M1.2 a PydanticAI agent
handles free-text claims; this function stays as the validated boundary.
"""
from __future__ import annotations

import json


def parse_claim(text: str) -> dict:
    try:
        raw = json.loads(text)
    except json.JSONDecodeError as exc:
        raise ValueError(f"claim must be a JSON object: {exc}") from exc

    if not isinstance(raw, dict):
        raise ValueError("claim must be a JSON object")

    for field in ("claimId", "policyNumber", "estimatedAmount"):
        if raw.get(field) in (None, ""):
            raise ValueError(f"{field} is required")

    return {
        "claimId": str(raw["claimId"]),
        "policyNumber": str(raw["policyNumber"]),
        "description": str(raw.get("description") or ""),
        "estimatedAmount": float(raw["estimatedAmount"]),
    }
```

```python
"""A2A delegation.

Which agents may be delegated to is configuration, never discovery. In M1 that
configuration is an environment variable; in M2 these become agentgateway route
names enforced at the gateway; in M6 Crossplane generates them from the Agent
CRD's delegation.allowedAgents field.

No spans are created here. The a2a-sdk telemetry extra and httpx instrumentation
emit the client spans and inject trace context.
"""
from __future__ import annotations

import json
import os
import uuid

import httpx


def allowed_agents_from_env(value: str | None = None) -> dict[str, str]:
    raw = value if value is not None else os.environ.get("NORTHSTAR_ALLOWED_AGENTS", "")
    agents: dict[str, str] = {}
    for entry in (raw or "").split(","):
        entry = entry.strip()
        if not entry:
            continue
        name, _, url = entry.partition("=")
        if name and url:
            agents[name.strip()] = url.strip()
    return agents


ALLOWED_AGENTS = allowed_agents_from_env()


class A2ADelegate:
    def __init__(
        self,
        base_url: str,
        agent_name: str,
        transport: httpx.BaseTransport | None = None,
        timeout: float = 120.0,
    ):
        self._base_url = base_url.rstrip("/") + "/"
        self._agent_name = agent_name
        self._transport = transport
        self._timeout = timeout

    async def send(self, payload: dict) -> dict:
        request = {
            "jsonrpc": "2.0",
            "id": uuid.uuid4().hex,
            "method": "message/send",
            "params": {
                "message": {
                    "role": "user",
                    "messageId": uuid.uuid4().hex,
                    "parts": [{"kind": "text", "text": json.dumps(payload)}],
                }
            },
        }

        async with httpx.AsyncClient(
            transport=self._transport, timeout=self._timeout
        ) as client:
            response = await client.post(self._base_url, json=request)
            response.raise_for_status()
            body = response.json()

        if "error" in body:
            raise RuntimeError(
                f"{self._agent_name} returned an error: {body['error'].get('message')}"
            )

        return _extract_json_result(body["result"], self._agent_name)


def _extract_json_result(result: dict, agent_name: str) -> dict:
    """Pull the last text part out of an A2A result and parse it as JSON."""
    parts = result.get("parts")
    if parts is None:
        history = result.get("status", {}).get("message", {})
        parts = history.get("parts", [])

    texts = [p.get("text") for p in parts or [] if p.get("kind") == "text" and p.get("text")]
    for text in reversed(texts):
        try:
            return json.loads(text)
        except json.JSONDecodeError:
            continue
    raise RuntimeError(f"{agent_name} returned no JSON payload: {result!r}")
```

```python
"""A2A executor for claims-agent.

M1.1 delegates unconditionally to settlement-agent. Policy and assessment
agents join the fan-out in M1.3; a policy decision joins the path in M2.
"""
from __future__ import annotations

import json
import logging

from a2a.server.agent_execution import AgentExecutor, RequestContext
from a2a.server.events import EventQueue
from a2a.utils import new_agent_text_message

from delegation import ALLOWED_AGENTS, A2ADelegate
from intake import parse_claim

logger = logging.getLogger(__name__)


class ClaimsAgentExecutor(AgentExecutor):
    def __init__(self, delegates: dict[str, A2ADelegate] | None = None):
        if delegates is not None:
            self._delegates = delegates
        else:
            self._delegates = {
                name: A2ADelegate(url, name) for name, url in ALLOWED_AGENTS.items()
            }

    def _delegate(self, name: str) -> A2ADelegate:
        try:
            return self._delegates[name]
        except KeyError:
            raise RuntimeError(
                f"claims-agent is not permitted to delegate to {name!r}; "
                f"permitted: {sorted(self._delegates)}"
            ) from None

    async def execute(
        self, request_context: RequestContext, event_queue: EventQueue
    ) -> None:
        # Named request_context, not context: `context` shadows
        # opentelemetry.context, which Task 7 imports here.
        claim = parse_claim(request_context.get_user_input())

        await event_queue.enqueue_event(
            new_agent_text_message(f"Claim {claim['claimId']} received. Investigating.")
        )

        settlement = await self._delegate("settlement-agent").send(
            {
                "claimId": claim["claimId"],
                "amount": claim["estimatedAmount"],
                "currency": "EUR",
            }
        )

        await event_queue.enqueue_event(
            new_agent_text_message(
                json.dumps(
                    {
                        "claimId": claim["claimId"],
                        "policyNumber": claim["policyNumber"],
                        "paymentId": settlement.get("paymentId"),
                        "amount": settlement.get("amount"),
                        "currency": settlement.get("currency"),
                        "status": settlement.get("status"),
                        "narrative": settlement.get("narrative"),
                    }
                )
            )
        )

    async def cancel(
        self, request_context: RequestContext, event_queue: EventQueue
    ) -> None:
        raise NotImplementedError("claims-agent does not support cancellation in M1")
```

```typescript
export type Claim = {
  claimId: string;
  policyNumber: string;
  description: string;
  estimatedAmount: number;
};

export type ClaimResult = {
  claimId: string;
  paymentId?: string;
  amount?: number;
  currency?: string;
  status?: string;
  narrative?: string;
};

type TextPart = { kind: "text"; text: string };

export type JsonRpcRequest = {
  jsonrpc: "2.0";
  id: string;
  method: "message/send";
  params: {
    message: {
      role: "user";
      messageId: string;
      parts: TextPart[];
    };
  };
};

function newId(): string {
  return crypto.randomUUID().replace(/-/g, "");
}

export function buildSendMessageRequest(claim: Claim): JsonRpcRequest {
  return {
    jsonrpc: "2.0",
    id: newId(),
    method: "message/send",
    params: {
      message: {
        role: "user",
        messageId: newId(),
        parts: [{ kind: "text", text: JSON.stringify(claim) }],
      },
    },
  };
}

function extractJsonResult(result: unknown): ClaimResult {
  const container = result as { parts?: TextPart[]; status?: { message?: { parts?: TextPart[] } } };
  const parts = container.parts ?? container.status?.message?.parts ?? [];
  for (const part of [...parts].reverse()) {
    if (part.kind !== "text" || !part.text) continue;
    try {
      return JSON.parse(part.text) as ClaimResult;
    } catch {
      // Progress updates are plain prose, not JSON. Keep looking.
    }
  }
  throw new Error("agent returned no JSON payload");
}

export async function sendClaim(baseUrl: string, claim: Claim): Promise<ClaimResult> {
  const response = await fetch(`${baseUrl.replace(/\/$/, "")}/`, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify(buildSendMessageRequest(claim)),
  });

  if (!response.ok) {
    throw new Error(`claims-agent returned HTTP ${response.status}`);
  }

  const body = (await response.json()) as { error?: { message: string }; result?: unknown };
  if (body.error) {
    throw new Error(body.error.message);
  }
  return extractJsonResult(body.result);
}
```

```tsx
import { getTracer, initTelemetry } from "../telemetry";

const CLAIMS_AGENT_URL =
  process.env.NEXT_PUBLIC_CLAIMS_AGENT_URL ?? "http://localhost:19001";

  claimId: "CLM-1842",
  policyNumber: "POL-77120",
  description: "Rear-end collision at a junction",
  estimatedAmount: 6200,
};

export default function Page() {
  const [claim, setClaim] = useState<Claim>(DEFAULT_CLAIM);
  const [log, setLog] = useState<string[]>([]);
  const [result, setResult] = useState<ClaimResult | null>(null);
  const [busy, setBusy] = useState(false);

  useEffect(() => {
    initTelemetry();
  }, []);

  async function submit(event: React.FormEvent) {
    event.preventDefault();
    setBusy(true);
    setResult(null);
    setLog([`Submitting ${claim.claimId}…`]);

    // The browser owns the root span. Everything downstream is its child.
    // startActiveSpan returns the callback's value, so awaiting it awaits the
    // whole submission.
    await getTracer().startActiveSpan("claim.submit", async (span) => {
      span.setAttribute("northstar.claim.id", claim.claimId);
      span.setAttribute("northstar.policy.number", claim.policyNumber);

        const settled = await sendClaim(CLAIMS_AGENT_URL, claim);

          code: SpanStatusCode.ERROR,
          message: error instanceof Error ? error.message : String(error),
        });
        setLog((entries) => [
          ...entries,
          `Failed: ${error instanceof Error ? error.message : String(error)}`,
        ]);
        return null;
      } finally {
        span.end();
        setBusy(false);
      }
    });
  }

  return (

      <h1>Northstar Insurance</h1>
      <p>File a vehicle-damage claim.</p>

          Claim ID

            style={{ display: "block", width: "100%" }}
          />
        </label>
        <label style={{ display: "block", marginBottom: 8 }}>
          Description
          <textarea
            value={claim.description}
            onChange={(e) => setClaim({ ...claim, description: e.target.value })}
            style={{ display: "block", width: "100%" }}
          />
        </label>
        <label style={{ display: "block", marginBottom: 16 }}>

            value={claim.estimatedAmount}
            onChange={(e) =>

            }
            style={{ display: "block", width: "100%" }}
          />
        </label>

          {busy ? "Submitting…" : "Submit claim"}
```

```python
        if claim_id is not None:
```

```go
// claimIDFromBaggage annotates the current span with the claim id carried in
// W3C baggage. The Go SDK has no baggage span processor, so our own middleware
// does the same job explicitly.
func withClaimID(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if member := baggage.FromContext(r.Context()).Member("northstar.claim.id"); member.Value() != "" {
			trace.SpanFromContext(r.Context()).SetAttributes(
				attribute.String("northstar.claim.id", member.Value()),
			)
		}
		next.ServeHTTP(w, r)
	})
}
```
