# Pinned to the current PyPI releases for all nine OpenTelemetry
# distributions in this file (verified against pypi.org's own JSON API, not a
# local cache); the same versions the other four Python services in this
# repo carry.
#
# The version matters for trace continuity (docs/upstream-findings.md
# Finding 11): `sdk/trace/__init__.py`'s flag handling inherits the W3C Trace
# Context Level 2 RANDOM_TRACE_ID bit (0x02) from an extracted remote parent,
# so a traceparent carrying that bit from agentgateway is preserved rather
# than stripped. payments-api's otel-go extractor must be new enough to
# accept a version-00 traceparent with 0x02 set (currently v1.46.0), or the
# payments-mcp -> payments-api hop falls out of the trace.
